# 🧰 Системный администратор → Сетевой инженер – Портфолио

## Обо мне

Я системный администратор, который строит свою карьеру в направлении сетевой инженерии. Этот репозиторий — моё практическое портфолио, отражающее мои умения на реальных лабораторных работах.

## 🎯 О проекте

Это мой домашний лабораторный стенд, который полностью повторяет инфраструктуру реальной компании среднего размера. Здесь я отрабатываю навыки системного и сетевого администрирования, используя гетерогенную среду (Windows + 3 дистрибутива Linux + pfSense).

## 🏗️ Архитектура

- **16 виртуальных машин** (Windows Server, Windows 11, Ubuntu, Debian, CentOS, pfSense)
- **4 VLAN** (Management, Servers, Office, Guests)
- **2 гипервизора** (Proxmox + KVM на ноутбуке с ZFS-репликацией)
- **Отдельные сервера** для DHCP, NTP, DNS, прокси, RADIUS, VPN, логов, бэкапов, мониторинга.

## 🛠️ Стек технологий

| Категория | Технологии |
|-----------|------------|
| **Гипервизоры** | Proxmox VE 8.2, KVM |
| **ОС** | Windows Server 2022, Windows 11, Ubuntu 22.04, Debian 12, CentOS 9 Stream, pfSense |
| **Сеть** | VLAN, DHCP, DNS, NTP, OSPF (в плане), NAT, WireGuard, pfSense |
| **Безопасность** | AD DS, GPO, AppLocker, FGPP, pfSense Firewall, DHCP Snooping, DAI, Port Security, FreeRADIUS |
| **Мониторинг** | Zabbix, Grafana, NetBox, rsyslog |
| **Автоматизация** | Python, Bash, Docker, Git |

## 📁 Структура репозитория

- `docs/` — Архитектура, IP-план, схемы, процедуры
- `configs/` — Конфигурационные файлы всех сервисов
- `scripts/` — Скрипты автоматизации (Python, Bash, PowerShell)
- `screenshots/` — Скриншоты процесса настройки
- `labs/` — Лабораторные работы (Cisco Packet Tracer, GNS3)
- `templates/` — Шаблоны ВМ и конфигураций
